The Deepgram Changelog · build your own

Do you need llms.txt?

No. The podcast needs every changelog entry, its date, and its full text. An llms.txt index or an RSS feed can both provide that.

What each one looks like

A list of links, or a feed of posts

llms.txt index 
- [September 17, 2026](https://…/changelog/2026/9/17.md)
- [September 15, 2026](https://…/changelog/2026/9/15.md)

Each link opens a clean markdown page for that day.

RSS feed 
<item>
  <pubDate>Thu, 17 Sep 2026</pubDate>
  <content:encoded><h2>Nova-3 Pharma…</h2>…
</item>

Each item carries its date and the whole post as HTML.

How each becomes a day page

The feed does three extra chores

With llms.txt
  1. Read the list of links.
  2. Take the date from the link: /2026/9/17.md or "September 17, 2026".
  3. Download each page. It's already markdown.
  4. Drop the > notes about the page itself.
Without it: RSS or Atom
  1. Read every item and its date.
  2. Turn the HTML into markdown. extra
  3. Merge items from the same day into one page. extra
  4. No heading? Use the item title, unless the title is just a date. extra

Headings, lists, links, and code survive the HTML conversion. Styling doesn't, and the writer doesn't need it.
